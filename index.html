Which model wrote this?

Paste any text. Philology compares it with 2,589 texts from nine language models, names the closest match, tells you how often that call is right, and highlights what gave it away. It runs in your browser, so your text never leaves the page.

Result

How it works

Every model has habits: favourite word endings, how it uses commas and dashes, how it opens a sentence. Philology learns those habits from texts with known authors and looks for them in yours.

pipeline
your text                                     "…the model says, …"
  → cut into every 1–4 character sequence     "s"  "sa"  "say"  "ays,"  "s, "  …
  → weight each one by tf-idf                 40,000 numbers
  → multiply by each model's weights          one score per model
  → softmax                                   probabilities that add up to 1
verdict                                       the model with the highest probability

What the research found

Three studies asked whether you can tell which model wrote a text. You can, very reliably, as long as you don't ask a model. Every number is measured on prompts the method never saw.

Limits

It always picks one

Human writing, or text from a model not listed, still gets matched to the closest of the nine.

2026 snapshots

Trained on outputs from June to October 2026. Newer model versions may write differently.

Unedited text

Paraphrased or edited text was never tested. Translation cut accuracy to 57–70%.

Length matters

Below about 400 characters it is much less reliable. Each result shows the accuracy for its length.
