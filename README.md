# Philology

Which language model wrote this text? Paste a text and Philology names the most
likely author out of nine models, with how reliable that call is and what in the
text gave it away. Everything runs in the browser.

Built from the CompLLM, LangLLM and WLLFM studies (Adrian Erlikhman, Michael
Tarekegn, Philo Juang). This repository holds only the built website; it is
generated from `site/` in the research repository.
